# tiancaihhh
这是源代码的小窝

## 项目简介 / Project Description

这是一个简单的Python问候程序，可以向用户说"你好"。

This is a simple Python greeting application that says "Hello" (你好) to users.

## 使用方法 / Usage

### 运行程序 / Run the application

```bash
python hello.py
```

### 运行测试 / Run tests

```bash
python test_hello.py
```

或者 / Or:

```bash
python -m unittest test_hello.py
```

## 功能 / Features

- 基本问候功能 / Basic greeting functionality
- 支持自定义名字问候 / Support for personalized greetings
- 完整的单元测试 / Complete unit tests
